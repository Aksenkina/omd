## ДОМАШНЯЯ РАБОТА №1
## Файлы
- `hw1_task1.py` — задачи на множества (склады в Москве и Казани).
- `hw1_task2.py` — анализ поисковых запросов (использовала Counter).
- `hw1_task3.py` — работа со списком заказов.
- `hw1_task4.py` — статистика магазина.
- `hw1_task5.py` — анализ отзывов.
## Установка и запуск
Каждая задача находится в отдельном файле (от `hw1_task1.py` до `hw1_task5.py`). 
Дополнительные библиотеки устанавливать не нужно.
Чтобы запустить нужную задачу, откройте терминал в папке проекта и введите:
python hw1_task1.py

## ДОМАШНЯЯ РАБОТА №2
## Описание
Программа читает файл `Corp_Summary.csv` и строит отчеты по департаментам.
## Как запустить
В файле `hw2.py` в самом низу найдите вызов `main(1)` (или `main(2)`, `main(3)`) и поменяйте цифру на нужный номер отчета:
- `1` — Иерархия департаментов и команд
- `2` — Сводка по департаментам (кол-во, мин/макс зарплата, средняя)
- `3` — Сохранение сводки в файл `report.csv`
Запуск через терминал:
python hw2.py
