## Домашняя работа 3: Анализ данных о Нобелевских лауреатах

В данном проекте реализован парсинг и разведочный анализ данных (EDA) о лауреатах Нобелевской премии на основе предоставленного JSON-файла.

## Структура проекта:
- `json_dict_processing.py` — ядро проекта (core), содержит функции для обработки вложенных JSON-словарей.
- `prizes_configs.py` — конфиги для парсинга информации о призах.
- `laureates_configs.py` — конфиги для парсинга информации о людях и организациях.
- `dataset_helpers.py` — вспомогательные функции для фильтрации (WHERE) и группировки (GROUP BY).
- `aggregations.py` — функции для расчета агрегаций (среднее, медиана, топ-N).
- `eda_analysis.py` — основной скрипт с техническим анализом и визуализацией данных.

## Основные инсайты:
1. Топ-5 стран по рождению: США лидируют с огромным отрывом (299 лауреатов), далее идут Великобритания (94), Германия (82), Франция (61) и Япония (31).
2. Возраст при награждении: Средний возраст лауреатов — 60.6 лет, медианный — 61 год.
3. Гендерное распределение: Наблюдается сильный перекос в сторону мужчин (931 против 69 женщин).
4. Отказы: В данных найдено 2 отказа от премий (Жан-Поль Сартр и Ле Дык Тхо).
5. Динамика: Количество награждений стабильно растет с каждым десятилетием (с 56 человек в 1900-х до 119 в 2000-х).

## Запуск:
Для запуска анализа и просмотра графиков выполните:
`python eda_analysis.py`

## Используемые библиотеки:
- `json` (встроенная) — для чтения и обработки JSON-файлов.
- `statistics` (встроенная) — для расчета средних значений и медианы.
- `matplotlib` — для построения графиков и визуализации данных (устанавливается отдельно: `pip install matplotlib`).
- `requests` — использовалась на этапе разработки для попытки загрузки данных через API, но в финальной версии проект работает с локальным файлом `laureates.json` (устанавливается отдельно: `pip install requests`).
