## Файлы
- `hw1_task1.py` — задачи на множества (склады в Москве и Казани).
- `hw1_task2.py` — анализ поисковых запросов (использовала Counter).
- `hw1_task3.py` — работа со списком заказов.
- `hw1_task4.py` — статистика магазина.
- `hw1_task5.py` — анализ отзывов.
## Установка и запуск
Каждая задача находится в отдельном файле (от `hw1_task1.py` до `hw1_task5.py`). 
Дополнительные библиотеки устанавливать не нужно.
Чтобы запустить нужную задачу, откройте терминал в папке проекта и введите:
python hw1_task1.py
